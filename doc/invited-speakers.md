# Invited Speakers

Invited speakers sit inside the relevant `_posts/` session file, not in a separate speakers list.

Once a speaker is confirmed:

1. Add a talk entry under `talks:` in that session's post.
2. Fill `author` with `given`, `family`, and `affiliation`.
3. Add an `abstract` if you have one, and keep `show_abstracts: true` on the post.
4. Mark unconfirmed names with `tentative: true` until they are firm.

The programme overview picks up organisers from the same files. Workshop organisers can edit those files through GitHub (giki) or through the [Decap admin](./decap.md).
