# Documentation for Building the Sorrento Meeting

Congratulations, or commiserations, on being asked to organise the Sorrento Meeting. Organising a meeting is one of the most helpful things you can do for a research community. But if it's your first time organising one, it can also be one of the most stressful.

The aim of this document is to ease that stress. It integrates a [checklist of things you need to do](./checklist.md) and explains how to update this website once they're done. The site can also be maintained by the [giki philosophy](./giki.md) — an approach to sharing the load of maintaining the website whilst maintaining final control.

Building a meeting website may seem like an extra step and a hassle. The goal is to make the website the central repository for communicating between chairs about what the meeting is doing, while generating a page for attendees, speakers, and sponsors.

The site is hosted on [GitHub](http://github.com). This is convenient as it allows for multiple organisers to make changes from different locations, and git alongside GitHub hosting is a great way to manage this.

The site is compiled using [Jekyll](https://jekyllrb.com/). Jekyll is a static web page generator written in Ruby. It is automatically integrated with GitHub, so the site compilation is part of the service that GitHub provides.

Rather than editing HTML directly, most of the site is generated by editing YAML front matter in Markdown/HTML files. These files are read by Jekyll using a customised remote theme (hosted at <https://github.com/cabrerac/jekyll-theme-sorrento>). This theme makes it easier to generate a website without editing large amounts of HTML.

## Creating the New Year's Repo

1. Go to <https://github.com/new> and create a repo named `sorrentoXXXX` (replace `XXXX` with the year).
2. Select "Create from Template" and use `lawrennd/sorrento-template` as the template.
3. Set the repo to **public**.
4. Edit `_config.yml` and replace all `XXXX` occurrences with the year.
5. In the repo settings, enable GitHub Pages using the **GitHub Actions** source.
6. The site will be published at `https://lawrennd.github.io/sorrentoXXXX/`.

## First two tasks (do in parallel)

1. Confirm the [venue and dates](./venue.md) — the Grand Hotel Vesuvio has been our home, but if that ever changes, update `_config.yml` accordingly.
2. [Build your organisation team](./checklist.md).

You should start on these two jobs as soon as you have agreed to run the meeting.
