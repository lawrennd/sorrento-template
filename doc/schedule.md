# The Schedule

The meeting schedule is compiled once all the workshop organisers and plenary speakers are confirmed.

A good idea is to anchor your schedule around the invited speakers. You can frame each session by selecting a keynote to open it.

Fine tuning the schedule to fit everything in can be a challenge. There will be a balance between the number of talks, panel discussions, and working sessions within each workshop.

One thing is clear: there is no *right* answer in how to do things. Different attendees prefer different approaches.

Bear in mind that a key advantage of a small, residential meeting is the time people have to talk informally. An overly packed schedule can actually reduce the value of being together in person. Don't forget to leave time for breaks, meals, and unstructured discussion.

## How to Update the Schedule

The schedule is generated from the `_posts/` directory. Each file in `_posts/` represents one session (a workshop day or plenary). Add or edit files there to update the programme.

- See the example skeleton files in `_posts/` for the required YAML format.
- The programme overview page (`program.html`) is auto-generated from all posts with `programme_show: true`.
- Posts are ordered using `programme_order` — lower numbers appear first.

The schedule appears online directly, which allows for late changes without reprinting anything. Ideally, attendees will also be able to fix any errors using the [giki philosophy](./giki.md).
